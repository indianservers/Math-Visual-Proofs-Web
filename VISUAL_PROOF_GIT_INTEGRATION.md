### Dependencies / assets added

- **Vendored for offline use** under `public/vendor/`: KaTeX (from local `katex`), three.js r128, Font Awesome 6.4 (css + webfonts), Pavan logo asset.
- **npm packages added**: `react-katex` (Ishwarya), `lucide-react` (Praveen + Harikishore), `canvas-confetti` + `@types/canvas-confetti` (Harikishore).
- **Shared React source** vendored under `vendor/harikishore/` (Harikishore proofs share `data/types/utils/common`); Tailwind `@source` added so their utility classes are generated by the app's existing Tailwind v4.
- **Integration mechanism**: `app/components/EmbeddedHtmlProof.tsx` hosts self-contained HTML proofs (bundled `srcDoc`, responsive, unmount cleanup); React proofs render natively client-only inside `VisualProofShell`.
