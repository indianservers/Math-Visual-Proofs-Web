Slope Formula

A slope triangle makes rise y₂ − y₁ and run x₂ − x₁ visible for any two points.

▥   Beginner
◷   7 min

Controls

Slope

Slope type guide

↗Positive↘Negative→Zero↕Undefined

✧   Why it works

1Form a right triangle using projections.
2Rise is vertical change, run is horizontal change.
3Slope is rise divided by run.
m = (y₂ − y₁) / (x₂ − x₁)
Build a slope triangle, then compare rise and run.

Proof in one line

A and B
→
Slope triangle
⇒
rise = y₂−y₁
&
run = x₂−x₁
⇒
m = rise/run
⇒
m = Δy/Δx
