Why are we dragging the purple point?Try moving it slowly and watch what changes.
1. The purple pointIt marks the place on the curve we are using to choose a rectangle's height.
2. Drag it left or rightThe point moves to a new x-value, so the height we read from the curve can change.
3. Watch the rectangleThe rectangle height follows the curve at the selected point. Its width is Δx.
4. Watch the totalWhen the heights change, the rectangle areas change, so the Riemann-sum estimate changes too.
In simple words: we are using easy rectangles to estimate the harder-to-measure area under the curved line.

✦ What are we doing?

We want to find how much space is underneath the curve. A curve is tricky to measure directly, so we use rectangles to make a smart estimate.

1
Choose the part of the curvea is where we start and b is where we stop.
athe part we measureb
2
Split it into piecesn tells us how many pieces we make. More pieces means thinner rectangles.
3
Build a rectangle at each pieceWe use the curve's height to make each rectangle.
4
Add all the little areasFor one rectangle: area = width × height. Add every rectangle to get the estimate.
Sn ≈ Σ f(x) · Δx
5
Use more rectanglesAs n gets bigger, the rectangles fit the curve better and the estimate gets closer.
